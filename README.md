# Портфолио Васили Шакиржановой

Существующий сайт на русском языке: HTML, CSS и JavaScript без фреймворка,
зависимостей npm, серверного кода и внешних библиотек. Все изображения, шрифты
и резюме хранятся в `assets/`.

Адрес GitHub Pages: https://vasilya-shakirzhanova.github.io/portfolio/

## Редактирование в Codex

Редактируйте исходные файлы в корне этого репозитория:

- `index.html` — главная страница;
- `case-premier.html` — RUTUBE / PREMIER;
- `case-bre.html`, `case-security.html`, `case-tour.html` — остальные кейсы;
- `case-rutube.html` — переход к рекламному кабинету в общем кейсе;
- `styles.css`, `script.js` — оформление и взаимодействия;
- `assets/` — настоящие изображения, шрифты и PDF резюме.

Не редактируйте отдельно `dist/`: это копия исходных файлов для публикации,
сохранённая с предыдущего хостинга. Сборка обновляет её автоматически.
Локальный каталог `vasilya-shakirzhanova/` служит старым адресом предпросмотра,
содержит символические ссылки и не загружается в GitHub.

## Проверка и предпросмотр

Требуется только Python 3.9 или новее; установка пакетов не нужна.

```sh
python3 scripts/build_site.py
python3 -m http.server 4173 --directory dist
```

Откройте http://127.0.0.1:4173/ для локального предпросмотра.
Сборка проверяет локальные ссылки, якоря, пути изображений и шрифтов,
а затем копирует исходники без изменения дизайна в `dist/`.
Все пути относительные: страницы работают и в `/portfolio/`, и в корне домена.

## Автоматическая публикация

В GitHub откройте **Settings → Pages → Build and deployment → Source**
и выберите **GitHub Actions**. Workflow `.github/workflows/pages.yml` запускается
после каждого push в `main`; также его можно запустить вручную во вкладке Actions.
Он проверяет исходники, собирает статические файлы и публикует только `dist/`.
Для публикации используется встроенный `GITHUB_TOKEN`; собственный токен
в коде или в Secrets репозитория не нужен.

После правок:

```sh
python3 scripts/build_site.py
git add .
git commit -m "Update portfolio content"
git push origin main
```

Дождитесь зелёного статуса workflow в Actions. Не загружайте пароли, токены,
личные настройки и `.env`-файлы. Контакты, рабочие экраны и полное резюме
опубликованы по разрешению владельца.

`.openai/hosting.json` сохраняет идентификатор ранее созданного сайта Sites.
Это не секрет, и GitHub Pages не использует этот файл. Он не попадает
в публикуемый каталог `dist/`.
